# Lista de tarefas

Lista de tarefas no navegador com prioridades, filtros de conclusão e alternância de tema.

**Contexto:** Projeto de frontend.  
**Tecnologias:** HTML, CSS e JavaScript.

## Visão do projeto

A interface oferece criação de tarefas, níveis de prioridade, filtros de tarefas pendentes/concluídas e tema claro/escuro.

## Executar localmente

Clone o repositório e sirva os arquivos localmente. Com Python instalado:

```bash
git clone https://github.com/GuiPaicheco/ToDoList-HTML.git
cd ToDoList-HTML
python -m http.server 8000 --bind 127.0.0.1
```

Abra [http://127.0.0.1:8000/index.html](http://127.0.0.1:8000/index.html). Preserve as pastas de imagens, estilos e scripts. Recursos externos, quando usados pela página, podem exigir conexão com a internet.
